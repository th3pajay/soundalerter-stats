How the data gets here

1 · In gameThe addon keeps the realm's 7-day picture and saves its export line when you log out.
2 · Saved fileThe game writes it to WTF\…\SavedVariables\SoundAlerter.lua.
3 · CompanionA small PowerShell script notices the change and reads only that line.
4 · GitHubIt commits data/<realm>/<day>.sag1 to this site's repository with a token that can write only here.
5 · This pageGitHub Pages serves the update within a few minutes; every day stays for trends.
